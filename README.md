# Obsidian-utils

A repository for dataviews and templates for [obsidian](https://obsidian.md/)

To use this repository, clone it in the root of your obsidian note vault.

# Requirements
- [Dataview](https://blacksmithgu.github.io/obsidian-dataview/) plugin
- [Templater](https://silentvoid13.github.io/Templater/introduction.html) plugin
